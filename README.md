# لمّوعة تركض • فرفشة

لعبة ويب ثلاثية الأبعاد (Three.js) فيها ٨ مهمات بمواقف مختلفة في الرياض + تحدي بلا نهاية.
لمّوعة تتكلم بصوت مسجّل (Edge ar-SA-ZariyahNeural) وفيها زر تسجيل فيديو عمودي 9:16 وأفقي 16:9.

- `npm run dev` تشغيل محلي
- `npm run build` بناء
- `npm run voice` توليد ملفات الصوت من `src/lines.js`
